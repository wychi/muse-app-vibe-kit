How it works

Tap the DEV button → Report issue records the current page ID and opens the describe step right away (category optional, description required). Add a screenshot only if it helps — it goes through the annotator and lands back as a thumbnail. Submit sends the JSON debug bundle through your wiring.submitReport, with the annotated PNG attached only when you took one.
