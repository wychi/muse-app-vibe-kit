@muse-app-vibe-kit/screenshot

Faithful full-page PNG screenshots, hardened for mobile webviews. This page is intentionally taller than your viewport — hit the button and the capture below should contain all of it, top to footer. Recipe & source: on GitHub.

What it handles

📏 True full page

Measures the real scroll container and renders the whole document, not just the viewport.

📱 WebView-hardened

Sticky-to-relative clone handling and an image overlay fallback for WKWebView's foreignObject quirks.

🧹 Clean captures

hideSelectors removes UI chrome (like the capture button) only from the render clone.

📐 Honest geometry

Every capture returns a measurement record: container, viewport, output size, scale.

This band is 120vh tall.

If the screenshot below shows this entire gradient — and the footer after it — the full-page claim holds.

↑ an inline image, to exercise the image pipeline

Drop-in usage

import html2canvas from "html2canvas";
import { captureFullPageScreenshot } from "@muse-app-vibe-kit/screenshot";

const { blob, measurement } = await captureFullPageScreenshot(html2canvas, {
  hideSelectors: ["#capture-btn"],
});
console.log(measurement.outputWidth, "x", measurement.outputHeight);
